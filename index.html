    🔑 Claude API キー

    📱 iPhone で使うとき

    Safari で開き，共有ボタン（□↑）から「ホーム画面に追加」してください．アプリのように開けて，記録も消えにくくなります． 音声認識がうまく動かないときは，文字起こし欄をタップして，キーボードのマイク🎤で話しても入力できます．

    🔒 プライバシー

    APIキーと記録は，この端末のこのブラウザにだけ保存されます．共有の端末では使わないでください． まとめるときは，文字起こしたテキストだけが Anthropic API に送られます．録音した音声は保存しません （音声認識は，ブラウザの提供元（Apple や Google）のサーバーで処理されることがあります）．
